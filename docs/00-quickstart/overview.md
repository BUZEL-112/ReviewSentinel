# Overview

ReviewSentinel is a sentiment analysis system built for production concerns. You get: 
1. Fine-tuned DistilBERT
2. Real-time inference via FastAPI
3. Automated retraining on drift
4. LLM second-opinion for uncertain predictions

**Not for:** 
- Academic experiments
- Single-script prototypes
- Production-scale (>1M daily predictions) without modification

Start with the [First Prediction](first-prediction.md) if you want to see it run in 5 minutes.
